两个 IP 的数据已按视频主题独立拆分：火影视频（3个）评论 2335 条、蜘蛛侠视频（2个）评论 583 条，并各自去除粉丝刷屏噪音。去噪后两个 IP 的情感结构高度相近——均以中性期待为主（89-91%），正面约 7-9%，负面约 2%。火影侧负面集中在模式被指"FreeFire 换皮"和动漫化疲劳；蜘蛛侠侧负面集中在皮肤还原度不及旧版；两个 IP 共同的最迫切诉求是：上线内容品质要对得起玩家期待。

◈ 关键洞察

▸ 两个 IP 情感结构高度相似，不是一强一弱：去噪并按视频主题拆分后，火影（8.7% 正）和蜘蛛侠（7.2% 正）情感分布几乎一致，均为中性期待主导。原始数据中火影评论量更多，是因为火影视频有 3 个、蜘蛛侠只有 2 个，不代表玩家对火影 IP 的关注度更高。
▸ "FreeFire 换皮"是火影侧最大负面风险：多条评论用"free fire olmus"（变成 FF 了）批评模式技能体系，若上线后玩法仍无差异化，这个标签会快速扩散并主导负面口碑。
▸ 蜘蛛侠皮肤还原度是独立口碑变量：蜘蛛侠侧负面几乎全集中在"新版皮肤不如旧版"，与火影侧负面（模式内容）完全不同。两个 IP 的预防措施也完全不同——火影需在玩法层面突破，蜘蛛侠需在皮肤视觉层面突破。
▸ 动漫化疲劳是两个 IP 共同的背景噪音：火影（40条）和蜘蛛侠（4条）都有"射击游戏不该有这些"的声音，是与先游2一脉相承的长期情绪，建议在宣传上强调"技能体验升级"而非"动漫联动"。
▸ 上线时间询问是隐藏的购买意向信号：火影侧 82 条询问上线时间，是最大话题类别，说明玩家已产生购买意向在等官方确认，是转化窗口期，需及时释放上线信息。
