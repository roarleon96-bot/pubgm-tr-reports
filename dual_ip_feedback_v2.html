◈ 关键洞察

▸ 两个 IP 情感结构高度相似，不是一强一弱。去噪并按视频主题拆分后，火影（8.7% 正）与蜘蛛侠（7.2% 正）的情感分布几乎一致。原始数据中火影评论量更多，仅因视频数量差异（3 vs 2），不反映玩家 IP 偏好。
▸ 两个 IP 的负面风险方向完全不同，预防措施也应不同。火影侧需在玩法层面突破"FreeFire 换皮"认知；蜘蛛侠侧需在皮肤视觉层面超越旧版标准。混为一谈会导致优先级错乱。
▸ 动漫化疲劳是两个 IP 共同的背景噪音。火影（40条）和蜘蛛侠（4条）均有"战斗游戏不该变成这样"的声音，与先游 2 一脉相承。宣传侧建议强调"技能体验升级"而非"动漫联动"。
▸ 蜘蛛侠侧存在独特的外部借势机会。《Brand New Day》7月30日院线档期已被玩家自发关联，官方若同步宣传节奏可免费借力院线热度，是火影侧没有的额外传播窗口。
